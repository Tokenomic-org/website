{%- comment -%} Dashboard sidebar — the single nav tree for every `layout: dashboard` page. Each page used to carry its own hand-maintained copy. They had drifted: dashboard/events.html grouped eleven items under Main / Account while every other page grouped twelve under Main / Finance / Content / Progress, so the sidebar reordered itself as you navigated. This include is now the one tree; pages mark their own entry with --- dash_active: events --- in front matter, matching a `data-dash` key below. The same markup serves all three shell states (off-canvas drawer under 768, icon rail 768–1119, labelled sidebar at 1120 and up) — the CSS in assets/css/dashboard.css does the switching. There is deliberately no second nav tree for small screens: a synthesised mobile copy is a second information architecture to keep in sync, and it is what this include replaces. Icons are Font Awesome classes rather than the theme's `flaticon-*` spans. The flaticon webfont only ever loaded on some pages, and shared/assets/js/dashboard-layout.js was remapping the spans to Font Awesome at runtime for the mobile copy — so half the nav rendered from one icon set and half from another. Naming the real class here removes the remap and the flash. `data-dash` keys are read by the role gate in dashboard-layout.js, which hides entries the signed-in wallet has no role for. Keys must stay in sync with the GATES map there. {%- endcomment -%}
