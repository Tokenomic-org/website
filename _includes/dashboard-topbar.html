{%- comment -%} Dashboard topbar — 56px, sticky, rendered by _layouts/dashboard.html on every legacy dashboard page. It holds the controls that belong to the shell rather than to any one page: the drawer toggle below 768, the rail-expand toggle between 768 and 1119, the page title, and the theme toggle. Pages supply the title through front matter (`title:`), so none of them repeat this markup. Both toggles carry a real accessible name and `aria-expanded`, and both are display:none outside their breakpoint so they leave the tab order rather than staying focusable but invisible. The previous shell synthesised a "Menu" button in JavaScript with no aria-expanded and no name beyond its visible text. {%- endcomment -%}
